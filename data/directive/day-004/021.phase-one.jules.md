# Jules Prompt: Phase 1 Terminal Arbitration & Process Lifecycle (The Curses Handshake)

Implement **Phase 1: Terminal Arbitration & Process Lifecycle (The Curses Handshake)** within `apps/995.library/995.library/80.terminal.unit` to prevent TTY stream collision between the Blessed curses runtime and external text editor processes.

---

### Architectural Context & Invariants

1. **The Terminal Collision Hazard:** When Blessed initializes, it captures standard input in raw mode (`process.stdin.setRawMode(true)`) and renders into an alternate screen buffer (`\x1b[?1049h`). Launching an interactive text editor while Blessed owns the terminal triggers raw input contention, dropped keystrokes, and screen buffer corruption.


2. **The Curses Handshake Lifecycle:**
* **De-allocation (`screen.leave()`):** Restores canonical cooked terminal mode, re-enables cursor visibility, unbinds mouse tracking, and drops out of the alternate screen buffer.


* **Blocking Child Execution (`spawnSync`):** Spawns `$EDITOR` (falling back to `$VISUAL`, `code --wait`, `notepad`, or `vi`) with `{ stdio: 'inherit', shell: true }`. Node.js idles at **$0.00 compute cost** while the operator edits the target file.


* **Restoration (`screen.enter()`):** Upon editor process termination, re-enters the alternate screen buffer, reactivates raw mode, and executes `screen.realloc()` and `screen.render()` to restore the 12×12 grid without visual tearing.




3. **Repository Laws (AGENTS.md):**
* Immutability on `apps/995.library/995.library/**` is **permanently lifted** in this repository.


* All console telemetry and error statuses must strictly adhere to **7-bit pure ASCII** (`>>`, `[OK]`, `[FAIL]`, `::`).


* Reducers must wrap state in `clone(model, true)` and include a default passthrough.


* All actions must implement `Action<TerminalBit>`.

import clone from 'clone-deep'
import * as Act from './terminal.action'

import type State from '../99.core/state'

export function reducer(

            return Buzz.resumeTerminal(clone(model, true), act.bale, state)

            return Buzz.printTerminal(clone(model, true), act.bale, state)

export const editTerminal = (
    cpy: TerminalModel,
    bal: TerminalBit,
    _ste: State,
) => {
    const { spawnSync } = require('child_process')

    const targetFile = bal?.src || ''
    const editor =
        (bal?.dat as any)?.editor ||
        process.env.VISUAL ||
        process.env.EDITOR ||
        (process.platform === 'win32' ? 'notepad' : 'vi')

    const screen = cpy.screen
    let suspended = false

    // Step 1: Suspend curses runtime
    if (screen && typeof screen.leave === 'function') {
        try {
            screen.leave()
            suspended = true
        } catch {
            // Non-blocking degradation
        }
    }

    let spawnResult: any = null
    let spawnError: Error | null = null

    try {
        if (!targetFile) {
            throw new Error('No target file provided for editTerminal')
        }

        const args = (bal?.dat as any)?.args || [targetFile]
        spawnResult = spawnSync(editor, args, {
            stdio: 'inherit',
            shell: true,
        })
    } catch (err: any) {
        spawnError = err
    } finally {
        // Step 2: Restore curses runtime unconditionally
        if (suspended && screen) {
            try {
                if (typeof screen.enter === 'function') {
                    screen.enter()
                }
                if (typeof screen.realloc === 'function') {
                    screen.realloc()
                }
                if (typeof screen.render === 'function') {
                    screen.render()
                }
            } catch {
                // Ignore restoration errors
            }
        }
    }

    // Step 3: Fulfill bit resolver
    if (bal?.slv != null) {
        if (spawnError) {
            bal.slv({
                trmBit: {
                    idx: 'edit-terminal-error',
                    src: spawnError.message,
                    val: -1,
                },
            })
        } else {
            const exitCode = spawnResult?.status ?? 0
            bal.slv({
                trmBit: {
                    idx: exitCode === 0 ? 'edit-terminal' : 'edit-terminal-fail',
                    src: targetFile,
                    val: exitCode,
                    dat: spawnResult,
                },
            })
        }
    }

    return cpy
}
