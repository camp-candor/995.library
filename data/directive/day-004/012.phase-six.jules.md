### II. ARCHITECTURAL MISSION & REQUIREMENTS

Implement the **Phase Directive Scaffolder (`PHASE_DIRECTIVE_SCAFFOLDER`)** to automate the creation of sequential phase stacks and focus dividers within development day folders (`data/directive/day-XXX/`):

1. **Blessed TUI Multi-Step Modal Cascade (`menu.library.ts`):**
* Expose `Create Directive` (`ActDrt.CREATE_DIRECTIVE.split(']')[1]`) in the `LIBRARY MENU` choice list.


* When selected:
* **Step 1 (Day Selection):** Scan `data/directive/` for all `day-XXX` directories. Sort them in descending natural order (newest day first) and display a choice modal via `OPEN_CHOICE`.


* **Step 2 (Focus Label Input):** Trigger an interactive input modal via `OPEN_INPUT` prompting the operator for the divider label (e.g., `modernize-media-pipeline`).


* **Step 3 (Phase Count Selection):** Present a choice modal with options: `['1 Phase', '2 Phases', '3 Phases', '4 Phases', '5 Phases', 'Custom']`.


* **Step 4 (Custom Phase Input):** If `Custom` is selected, prompt for an integer via `OPEN_INPUT`.


* Dispatch `ActDrt.CREATE_DIRECTIVE` with `{ src: selectedDay, idx: label, val: phaseCount }` and print the outcome via `PRINT_MENU`.






2. **Sequential Stack Provisioning Engine (`directive.buzz.ts`):**
* Locate the target directory `data/directive/<selectedDay>/` and template directory `data/directive/day-000/`.


* **Monotonic Sequence Calculation:** Scan all existing files in the target directory matching `/^(\d{3})\./` to discover `maxPrefix`. Establish the starting pointer as `nextSeq = maxPrefix + 1`.


* **Focus Divider Copying:** Ingest `000.focus.cpn` from `day-000` (or target directory) and write it to the target directory as `${pad3(nextSeq)}.${label}.cpn`. Increment `nextSeq`.


* **Phase Pair Provisioning:** For each phase from `1` to `phaseCount`:
* Resolve the phase word (`one`, `two`, `three`, `four`, `five`, etc.).


* **Jules File:** Copy `000.xxxx.jules.md` (or `000.xxxx.jules`) from `day-000` to `${pad3(nextSeq)}.phase-${phaseWord}.jules.md`. Increment `nextSeq`.


* **Gravity / AG-Test File:** Copy `000.xxxxx.gravity.md` (or `000.xxxxx.gravity`, falling back to `000.xxxxx.ag-test.md`) from `day-000` to `${pad3(nextSeq)}.phase-${phaseWord}.gravity.md`. Increment `nextSeq`.




* Stream 7-bit ASCII telemetry receipts to `cns00` for every file written.


* Resolve `bal.slv({ drtBit: { idx: 'create-directive', src: targetDir, val: createdFiles.length } })` immediately.

```typescript
const PHASE_WORDS: Record<number, string> = {
    1: 'one',
    2: 'two',
    3: 'three',
    4: 'four',
    5: 'five',
    6: 'six',
    7: 'seven',
    8: 'eight',
    9: 'nine',
    10: 'ten',
    11: 'eleven',
    12: 'twelve',
    13: 'thirteen',
    14: 'fourteen',
    15: 'fifteen',
    16: 'sixteen',
    17: 'seventeen',
    18: 'eighteen',
    19: 'nineteen',
    20: 'twenty',
}

const getPhaseWord = (num: number): string => PHASE_WORDS[num] || String(num)
const pad3 = (num: number): string => String(num).padStart(3, '0')

export const createDirective = async (
    cpy: DirectiveModel,
    bal: DirectiveBit,
    ste: State,
): Promise<DirectiveModel> => {
    const fs = require('fs-extra')
    const path = require('path')

    const repoRoot = findRepoRoot()
    const targetDay = (bal?.src || 'day-000').replace(/[[\]]/g, '').trim()
    const rawLabel = (bal?.idx || 'focus').trim()
    const phaseCount = typeof bal?.val === 'number' && bal.val > 0 ? bal.val : 1

    const targetDayDir = path.join(repoRoot, 'data', 'directive', targetDay)
    const templateDayDir = path.join(repoRoot, 'data', 'directive', 'day-000')

    try {
        await fs.ensureDir(targetDayDir)

        if (ste) {
            await ste.hunt(ActCns.UPDATE_CONSOLE, {
                idx: 'cns00',
                src: `>> [DIRECTIVE] Scaffolding stack in ${targetDay} (${phaseCount} phases)...`,
            })
        }

        // 1. Calculate the next monotonic sequential index prefix
        const existingEntries = await fs.readdir(targetDayDir)
        let maxPrefix = -1

        for (const entry of existingEntries) {
            const match = entry.match(/^(\d{3})\./)
            if (match) {
                const num = parseInt(match[1], 10)
                if (num > maxPrefix) {
                    maxPrefix = num
                }
            }
        }

        let currentSeq = maxPrefix + 1
        const createdFiles: string[] = []

        // Helper to resolve template content with fallback extensions
        const readTemplateContent = async (baseNames: string[]): Promise<string> => {
            const searchDirs = [templateDayDir, targetDayDir]
            for (const dir of searchDirs) {
                for (const baseName of baseNames) {
                    const candidate = path.join(dir, baseName)
                    if (await fs.pathExists(candidate)) {
                        return await fs.readFile(candidate, 'utf8')
                    }
                }
            }
            return ''
        }

        // 2. Provision the focus divider (.cpn)
        const focusTemplateContent = await readTemplateContent([
            '000.focus.cpn',
            'focus.cpn',
        ])

        const dividerFileName = `${pad3(currentSeq)}.${rawLabel}.cpn`
        const dividerFilePath = path.join(targetDayDir, dividerFileName)
        await fs.writeFile(dividerFilePath, focusTemplateContent, 'utf8')
        createdFiles.push(dividerFileName)

        if (ste) {
            await ste.hunt(ActCns.UPDATE_CONSOLE, {
                idx: 'cns00',
                src: `>> [OK] writing data/directive/${targetDay}/${dividerFileName}`,
            })
        }

        // 3. Read base templates for Jules and Gravity/AG-Test pairs
        const julesTemplateContent = await readTemplateContent([
            '000.xxxx.jules.md',
            '000.xxxx.jules',
            '000.jules.md',
        ])

        const gravityTemplateContent = await readTemplateContent([
            '000.xxxxx.gravity.md',
            '000.xxxxx.gravity',
            '000.xxxxx.ag-test.md',
            '000.xxxxx.ag-test',
        ])

        // Determine secondary check suffix (gravity.md vs ag-test.md)
        let checkExt = 'gravity.md'
        if (
            (await fs.pathExists(path.join(templateDayDir, '000.xxxxx.ag-test.md'))) &&
            !(await fs.pathExists(path.join(templateDayDir, '000.xxxxx.gravity.md')))
        ) {
            checkExt = 'ag-test.md'
        }

        // 4. Provision sequential phase pairs
        for (let p = 1; p <= phaseCount; p++) {
            const phaseWord = getPhaseWord(p)

            // 4a. Jules Phase Directive
            currentSeq++
            const julesFileName = `${pad3(currentSeq)}.phase-${phaseWord}.jules.md`
            const julesFilePath = path.join(targetDayDir, julesFileName)
            await fs.writeFile(julesFilePath, julesTemplateContent, 'utf8')
            createdFiles.push(julesFileName)

            if (ste) {
                await ste.hunt(ActCns.UPDATE_CONSOLE, {
                    idx: 'cns00',
                    src: `>> [OK] writing data/directive/${targetDay}/${julesFileName}`,
                })
            }

            // 4b. Gravity / AG-Test Verification Directive
            currentSeq++
            const gravityFileName = `${pad3(currentSeq)}.phase-${phaseWord}.${checkExt}`
            const gravityFilePath = path.join(targetDayDir, gravityFileName)
            await fs.writeFile(gravityFilePath, gravityTemplateContent, 'utf8')
            createdFiles.push(gravityFileName)

            if (ste) {
                await ste.hunt(ActCns.UPDATE_CONSOLE, {
                    idx: 'cns00',
                    src: `>> [OK] writing data/directive/${targetDay}/${gravityFileName}`,
                })
            }
        }

        const relOutput = path.relative(repoRoot, targetDayDir).replace(/\\/g, '/')

        if (ste) {
            await ste.hunt(ActCns.UPDATE_CONSOLE, {
                idx: 'cns00',
                src: `>> [OK] Directive stack created in ${relOutput} (${createdFiles.length} files).`,
            })
        }

        if (bal && bal.slv != null) {
            bal.slv({
                drtBit: {
                    idx: 'create-directive',
                    src: relOutput,
                    val: createdFiles.length,
                    dat: {
                        targetDay,
                        label: rawLabel,
                        files: createdFiles,
                    },
                },
            })
        }
    } catch (err: any) {
        const errorMsg = err instanceof Error ? err.message : String(err)
        if (ste) {
            await ste.hunt(ActCns.UPDATE_CONSOLE, {
                idx: 'cns00',
                src: `:: [FAIL] Error in createDirective: ${errorMsg}`,
            })
        }
        if (bal && bal.slv != null) {
            bal.slv({
                drtBit: {
                    idx: 'create-directive-error',
                    src: errorMsg,
                },
            })
        }
    }

    return cpy
}
```
